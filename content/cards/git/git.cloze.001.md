Quelle commande crée un commit local à partir de l'index ?

```
git ____ -m "message"
```

## Réponse

commit

## Explication

`git commit` enregistre l'index dans l'historique de ce dépôt. Il ne publie rien sur le dépôt distant : ça, c'est `git push`.
