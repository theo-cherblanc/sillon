Qu'est-ce qu'un commit ?

## Réponse

Un instantané enregistré du projet, avec un auteur et un message.

## Explication

Git garde l'historique comme une suite de commits. Chacun désigne l'état des fichiers à ce moment-là, et le commit d'avant. Tant qu'on ne l'a pas poussé, il reste sur la machine.
