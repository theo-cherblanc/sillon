Que fait `git clone` ?

## Réponse

Il copie un dépôt sur la machine, historique compris.

## Explication

On obtient les commits, les branches distantes que Git a récupérées, et une copie de travail. Ce n'est pas un téléchargement du seul dernier dossier : l'historique vient avec.
