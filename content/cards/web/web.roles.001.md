À quoi servent HTML, CSS et JavaScript dans une page ?

## Réponse

HTML décrit le contenu, CSS son apparence, JavaScript son comportement.

## Explication

Le navigateur lit le HTML pour construire la page. Le CSS dit comment l'afficher. Le JavaScript réagit et modifie la page ensuite. On peut avoir une page sans JavaScript. On ne peut pas afficher un document sans structure.
