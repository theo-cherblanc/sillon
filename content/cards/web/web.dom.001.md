Qu'est-ce que le DOM ?

## Réponse

L'arbre de la page, construit par le navigateur, que le JavaScript peut lire et modifier.

## Explication

DOM veut dire Document Object Model. Le HTML est le texte source. Le DOM est la structure vivante : éléments, textes, attributs. Changer le DOM change ce qui est affiché.
