Quel mot manque pour attendre une promesse dans une fonction `async` ?

```js
const value = ____ promise
```

## Réponse

await

## Explication

`await` suspend la fonction jusqu'à ce que la promesse aboutisse, puis donne sa valeur. Il ne s'écrit que dans une fonction `async`.
