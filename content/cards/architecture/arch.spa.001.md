Qu'est-ce qu'une SPA ?

## Réponse

Une application d'une seule page : le navigateur charge un document, puis le JavaScript change l'écran.

## Explication

SPA veut dire single-page application. Changer de vue ne recharge pas forcément un nouveau document HTML. Le serveur fournit souvent une API, et le navigateur compose l'interface.
